# AI Automation for Solo Founders

The 5 AI tools that gave me back 20 hours/week and how you can use them too.

## The Tools

1. **Zapier** — Connect your apps without code
2. **Make (formerly Integromat)** — Complex workflows for power users
3. **Perplexity AI** — Search + answers (replacing Google)
4. **Gamma** — AI presentation generator
5. **Fireflies.ai** — Meeting notes and transcription

## How I Use Them

### Monday: Zapier
Automate new lead notifications from Shopify → Slack + Follow-up email.

### Tuesday: Make
Build complex order fulfillment workflows with conditional logic.

### Wednesday: Perplexity AI
Quick research on competitor strategies — ask "What are the best ecommerce ads for Q4?"

### Thursday: Gamma
Generate pitch decks for clients in minutes instead of hours.

### Friday: Fireflies.ai
Automatically transcribe client calls and extract action items.

## Results

After 3 months using this stack, I reclaimed 20+ hours/week and increased my Shopify store's revenue by 15% without adding additional ad spend.

## Get Started

1. Start with Zapier's free plan to automate one routine.
2. Add Make for more complex workflows after you hit the free tier limit.
3. Install Perplexity AI as your default search engine.
4. Use Gamma for all client presentations.
5. Set up Fireflies.ai for all client calls.

## Key Takeaways

- **Start small**: Automate one routine first, then expand.
- **Choose tools that integrate**: Zapier + Make + Perplexity + Gamma + Fireflies all connect via Zapier/Make.
- **Track ROI**: Measure time saved vs. subscription costs.
